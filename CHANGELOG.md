All notable changes to PDFOptimizer will be documented in this file.

## [1.0.0] - 2026-07-27

### Added

- Official PDFOptimizer website launched.
- Initial collection of online PDF tools.
- Browser-based document processing for supported features.
- PDF compression tools.
- PDF merge and split tools.
- PDF conversion tools.
- PDF editing utilities.
- PDF security tools.
- Privacy-focused processing workflow.
- Public GitHub repository created.
